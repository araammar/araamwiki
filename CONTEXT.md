## How to Use This Wiki

- Ask about any brand, concept, or strategy by name — pages exist for all of them
- Ask "what do we know about [topic]" for synthesis across pages
- Ask "find scripts/ideas for [brand]" to pull specific content
- Ask "show me everything related to [concept]" for cross-linked pages
- Ask "what frameworks do we have for [problem]" for strategy pages

## How Content Gets Added

1. Drop a file or YouTube URL
2. Say `ingest [filename]` or paste the URL
3. Claude decomposes it into wiki pages, cross-links everything, updates INDEX and LOG
4. Push: `git add wiki/ && git commit -m "ingest: [source]" && git push`
5. Re-upload this CONTEXT.md to the claude.ai project to keep it current
