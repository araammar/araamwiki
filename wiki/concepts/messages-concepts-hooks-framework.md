# Concept: Messages, Concepts, Hooks — The Three-Pillar Content Framework

## Summary

Every piece of content that performs is built from three distinct layers: a message (what you're saying), a concept (how you're saying it), and a hook (why someone stops). Most brands collapse all three into one undifferentiated "content idea" and wonder why output is inconsistent. Separating the layers makes the system modular — you can swap concepts with the same message, test hooks against the same concept, and build a content machine with predictable output.

---

## The Three Pillars

### Messages — What You're Saying

The core point being communicated. Three sources:

1. **Core value propositions** — the fundamental claims your brand makes (product benefit, differentiation, price point)
2. **Brand stories** — founder narrative, origin story, build-in-public moments, milestones
3. **Trending topics** — current discourse the audience is already in; brand angle on something happening now

**The messages layer is strategy, not content.** A brand should have a defined library of messages it is actively cycling through. Every piece of content should be traceable to a message.

---

### Concepts — How You're Saying It

The execution format. The same message can be executed as any of these:

| Concept Type | Description |
|---|---|
| **Transformation** | Before/after narratives showing change over time |
| **Credible explainer** | Authority figure explaining a topic with visible credentials |
| **Testimonial** | Classic social proof from real users |
| **Tutorial** | How-to content addressing actual product usage |
| **Reaction video** | Responding to brand content or other creators with commentary |
| **Rankings / ratings** | Expert opinions on products or services in a category |
| **Unpopular opinion** | Contrarian take the audience already secretly holds |
| **Provocative scenario** | Fictional situation illustrating a real point |
| **Definitive cultural statement** | Assertive claim about a trend that generates engagement without controversy |

The concept layer is execution — it lives between the message and the hook.

---

### Hooks — Why Someone Stops

The visual or narrative element that interrupts scroll before the message or concept registers. Four hook types:

1. **Familiar faces** — faces the audience recognizes (creators, celebrities, employees)
2. **Call-outs** — direct address to a specific person or situation ("If you're a founder who...")
3. **Visual uniqueness** — something unexpected in frame that breaks pattern-matching
4. **Poke in the pool** — intrusion into the viewer's experience; the feeling of being addressed directly

**Key principle:** "The hook doesn't really matter if they're measured and intelligent and credible after." A great hook that opens a weak concept is still a bad piece of content. The hook buys time. The concept earns attention. The message drives action.

---

## How to Use the Framework

**For a single piece of content:**
1. Choose the message (from your brand's defined message library)
2. Choose the concept (which execution format fits this message and audience moment?)
3. Choose the hook (which type stops this specific audience at this specific moment?)

**For a content calendar:**
Build a matrix. Three messages × five concepts = 15 content combinations per month before you've touched hooks. Add hook variations and you have a full quarter of content without repeating once.

**For testing:**
Run four variations over six weeks. Keep the message constant, change the concept. Compare performance. Let data override subjective preference. "Testing is your friend. Every piece of content you make is a strategy."
