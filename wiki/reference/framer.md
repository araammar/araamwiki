# Reference: Framer

## Overview

Framer is the recommended no-code website builder for creatives building portfolio sites, offer pages, and landing pages. It is used throughout this vault's offer design and creative business frameworks as the go-to tool for turning a productized offer into a live, purchasable page.

**Why Framer over alternatives:** Design-quality output, responsive templates that auto-adjust across desktop/tablet/mobile, fast setup via templates, and a strong ecosystem of free and paid themes ($0–$129 range) built specifically for portfolio and service businesses.

## Key Use Cases for Creatives

### 1. Portfolio Sites
Framer has purpose-built portfolio templates (e.g., Artemis) that display project work in visual card grids with project-level detail pages. Good for showing a wide body of work where buyers need to see quality before committing.

- Template example: **Artemis** — displays projects as interactive cards with all related work visible at a glance
- Template example: **Abstract** — dark mode, minimal template for a clean presentation

### 2. Offer Pages / Landing Pages
The primary use case for creative service businesses. An offer page in Framer should display:
- The specific deliverable, price, and timeline
- A preview of the output (e.g., a Figma file preview link showing what the deliverable actually looks like)
- Social proof (client logos, case studies)
- A clear CTA (book a call, buy now, join waitlist)

- Template example: **Drilio** — built for SaaS landing pages, works well for service offers
- Template example: **Swiss style** — portfolio + offer hybrid with project showcase

### 3. VSL Integration
Framer pages support embedded video (e.g., an 11-minute YouTube video embedded mid-page as a VSL — Video Sales Letter). This is the recommended format for higher-ticket offers where buyers need to hear the pitch, not just read it.

See: [[offer-design-for-creatives]] for VSL format and purpose.

### 4. Funnel Architecture
Framer supports multi-page funnels: a top-level page (portfolio or offer) feeds into sub-pages (detailed offer pages, booking pages, lead capture forms, waitlist sign-ups). Each page includes CTAs that move visitors into the next step.

## How to Get Started

1. Browse templates at framer.com — filter by "portfolio," "landing page," or "agency"
2. Most useful free templates: Abstract, Artemis (portfolio), Drilio (landing pages)
3. Install a template → swap your content in (images, text, project work)
4. Responsive styles update automatically — editing desktop updates tablet and mobile
5. Add links, effects, and styles via the right-hand panel
6. Publish immediately — no dev work required

The fastest path: pick a free template, swap in your content and pricing, publish. Perfecting it comes later. Getting it live is what matters.

## Contra

A separate platform (contra.com) that acts as a freelance marketplace where clients can discover creative freelancers. Good for landing page specialists, illustrators, and productized service providers. Framer builds the destination; Contra is one acquisition channel that drives traffic to it.
