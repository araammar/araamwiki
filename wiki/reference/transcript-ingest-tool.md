# Reference: Transcript Ingest Tool

## Overview

A two-pass tool for ingesting video transcripts into the Araamwiki. First pass: analyzes the transcript and identifies all extractable entities (concepts, ideas, strategies, brands, tools). Second pass: generates properly formatted wiki pages for each entity and saves them to the correct folders. Designed to decompose a single long transcript into many linked, cross-referenced wiki pages.

---

## Two-Pass Architecture

### Pass 1 — Analysis

Input: raw transcript text
Output: structured extraction manifest

The analysis pass identifies:
- **Concepts** — named ideas, frameworks, mental models
- **Strategies** — actionable playbooks, systems, step-by-step approaches
- **Ideas** — reel angles, content concepts, scored by the reel idea scoring system
- **Brands** — any brand mentioned with enough detail for a brand page
- **Tools** — software, platforms, systems described in enough detail for a reference page
- **Quotes** — specific quotable lines attributed to the speaker

### Pass 2 — Page Generation

Takes the extraction manifest and generates one wiki page per entity:
- Correct folder (`concepts/`, `strategies/`, `ideas/`, `brands/`, `reference/`)
- Correct format (matching the template for that folder type)
- Cross-links between all related pages
- Tags derived from topic and speaker

---

## Usage

### Bash (CLI)

```bash
# Full ingest — generates all pages
transcript-ingest [filename.md] --mode=full

# Quick pass — concepts and ideas only
transcript-ingest [filename.md] --mode=quick

# Concepts only
transcript-ingest [filename.md] --mode=concepts
```

### In-Chat

Drop the transcript text and say: `ingest [filename]`

Claude will run both passes automatically and create all pages per the CLAUDE.md ingest rules.

---

## Output Structure

For a 45-minute transcript, typical output:

```
Generated:
  concepts/  — 4-8 pages
  strategies/ — 2-4 pages
  ideas/      — 3-6 scored ideas
  brands/     — 0-2 brand pages
  reference/  — 0-2 tool pages

Updated:
  wiki/INDEX.md
  wiki/LOG.md
```

## Quality Rules Applied During Generation

From CLAUDE.md ingest rules:

1. Never create just one page — every transcript gets decomposed across multiple folders
2. Always link related pages using `[[wiki links]]`
3. Always update INDEX.md after every ingest
4. Always log in LOG.md — timestamp, source file, pages created/updated
5. Tag every page with relevant topics, brands, and hook types
6. Auto-create brand pages — if a brand appears with no existing page, create it
